自動網過了再做下面人工走查(自動網沒覆蓋的:版面、捲動、導向、文案、按鈕實際可點與否)。

## 人工走查(用 MCP / 瀏覽器,以實際帳號登入)
準備:每角色一個帳號(中心 SUPER_ADMIN、機關 ORG_ADMIN、委員 AUDITOR),以及涵蓋各階段的週期
(可用 demo:開立中 / 資料準備中 / 資料齊備 / 實地稽核 / 矯正執行中 / 結案 各一)。

### 中心(最高管理員)
- [ ] 開立中:建立週期(不需填日期)→ 週期頁「建議的下一步—去設定」按鈕可捲動到設定區;
      引導式精靈「設定文件繳交期限與稽核日期」**未設日期前不應已打勾**;編輯週期日期可設四日期,
      改硬日期跳確認。
- [ ] 資料準備中:資料準備頁可逐項「確認齊備/退回」;每區「催繳」鈕可寄信。
- [ ] 資料齊備→實地稽核:可指派委員 + 指派構面(策略/管理/管理OT/技術)。
- [ ] 實地稽核/矯正:彙整報告可看(委員評分總覽 + **委員填寫狀態異動**區);可一鍵轉缺失;
      逐項審查;追蹤催辦。
- [ ] 結案:確認用印掃描檔 → 結案;**看得到機關上傳的掃描檔,但自己沒有「上傳掃描檔」鈕**。

### 機關(機關管理員)
- [ ] 開立中:`/prep` **不可上傳/填說明**(無上傳鈕);無「確定繳交」。
- [ ] 資料準備中:可上傳/填無相關文件說明/確定繳交(技術檢測、實地稽核可分次)。
- [ ] 已繳交/已確認:該項鎖定,需中心退回才可改。
- [ ] 缺失/矯正:逐題填報→送審;填完**最後一筆**跳回「缺失與矯正」總覽。
- [ ] 結案前:用印掃描檔可上傳;**中心已確認或結案後不可再上傳**(顯示提示)。
- [ ] 不應看到:彙整報告、其他機關任何資料。

### 委員(稽核委員)
- [ ] 開立中 / 資料準備中:週期頁「資通安全檢核表 / 委員審閱 / 實地稽核」三張磚**鎖定不可點**
      (🔒 資料齊備後開放);直接打 `/checklist`、`/review`、`/audit` 應被導回;匯出/留言 API 應 403。
- [ ] 資料齊備起:上述三磚**解鎖可點**;可檢視機關檢核表、留審閱意見。
- [ ] 實地稽核:可評分(可只評負責構面)+ 手填檢核結果數量 + 逐條發現(可一鍵依項次排序);
      確認填寫完畢→鎖定;解除鎖定→中心彙整報告會出現「異動」紀錄。
- [ ] 不應看到:彙整報告(印自己的附件17 即可)、用印掃描檔、其他機關 / 未指派週期。

### 共通
- [ ] 檢核表填答:按符合度/儲存後**頁面不上跳**。
- [ ] 麵包屑、導覽、⌘K 不出現越權入口。
- [ ] 手機 / 平板斷點(側欄→抽屜)正常。

## 發現問題時
- 若屬「角色×階段」可見性/權限 → 八成該收斂進 `access-policy.ts` 的 `canAccess` + 補真值表,而非只改該頁。
