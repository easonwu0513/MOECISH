# 資通系統防護基準(中級)實作對照

> 依《資通安全責任等級分級辦法》附表十「資通系統防護基準」,本系統定級為**中**。
> 本文件逐條對照中級(含普級)要求與系統實作,並提供啟用手冊。
>
> **目前狀態:已實作、預設關閉。** 總開關 `SECURITY_BASELINE=1` 啟用後才生效;
> 未啟用時系統行為與實作前完全相同。

## 二、啟用手冊(一次完成)

```bash
# 1) 應用層旗標(/srv/moecish/.env 加入)
SECURITY_BASELINE=1
NEXT_PUBLIC_SECURITY_BASELINE=1   # 閒置登出為 build-time 旗標
# 可選參數(不加用預設):SB_LOCK_THRESHOLD=5 SB_LOCK_MINUTES=15
# SB_PW_MIN_LENGTH=12 SB_PW_MAX_AGE_DAYS=90 SB_IDLE_MINUTES=30 SB_LOGIN_RATE_MAX=20
# NEXT_PUBLIC_SB_IDLE_MINUTES=30

# 2) 重建+重啟(NEXT_PUBLIC 旗標需 build 注入)
cd /srv/moecish && npm run build && systemctl restart moecish

# 3) 備份與還原測試排程
systemctl enable --now moecish-backup.timer
systemctl enable --now moecish-restore-test.timer

# 4) 驗證
npm run audit:verify-chain          # 日誌鏈
systemctl list-timers 'moecish-*'   # 排程
```

## 三、啟用後的使用者影響(請先公告)

- 連續打錯密碼 5 次 → 鎖 15 分鐘
- 新設/變更密碼須 12 字元+三類字元,不可重用前三次
- 密碼 90 天到期,總覽頁會出現變更提醒
- 閒置 30 分鐘自動登出
- 既有密碼**不會**立即失效(效期從下次變更起算,避免上線日全員被鎖)
