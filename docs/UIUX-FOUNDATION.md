# MOECISH UI/UX 地基藍圖(2026-06-22)

> 來源:9 代理 UX 軍團(7 面向勘查 → 首席設計師綜整 → 資深 PM 批判)。本文為這次系統級改造的單一依據。

## 北極星
讓**中心 / 委員 / 機關**三種人,在**任何一頁、任何裝置**上,三秒內都能確定:
**「我是誰、我在哪一家醫院的哪一階段、我現在唯一該做的下一件事、按下去會發生什麼」。**
把 MOECISH 從「同一套版面塞不同數字」變成「為每個角色量身、由單一真實來源驅動、永不自我矛盾」的稽核工作台。

## 七條設計原則(地基)
1. **單一真實來源,杜絕平行漂移** — 每類設計決定只能有一個定義點(導航/階段名/角色稱謂/角色色/存檔模型現都有多份副本而分岔)。
2. **角色是一級資訊架構,不是 if(role) 補丁** — 三角色心智模型不同,骨架就該不同。
3. **永遠只有一個焦點:此刻唯一的下一步** — 等權入口造成選擇癱瘓。
4. **狀態轉換全程顯性化** — 按下去會發生什麼、能否反悔、會通知誰。
5. **脈絡(機關+年度+階段)是一級導航,放第一落點** — 現被擠在 H1 下方小字。
6. **選語意角色,不選尺寸/數值;元件預設即正確值。**
7. **行動裝置與無障礙是基線,不是二等公民。**

## 資深 PM 的關鍵裁決(務實批判)
- **診斷可信**;北極星正確。問題在「地基」定義過寬。
- **真承重牆只有 2 個**:`lib/nav-map.ts`、`lib/stage.ts`。
- **被錯排成地基的(降級/延後)**:`role-view.ts` 三角色骨架分流(換骨架級重構、回歸面積最大,先用「換指標組+文案」80% 解決即可)、`.ds-*` + CI lint 擋 89 處 arbitrary alpha(防腐化非修當前痛點,lint 設 warning 不 block)、一卡一彩底/surface 階梯(polish,延後)、週期內持久次級導航(中型工程,先把麵包屑修對即可)。
- **核心建議**:把「地基」從 4 phase 串行,收斂成「**2 真地基 + N 個獨立可出貨改善**」,解開序列耦合,避免低風險文案修被高風險重構拖住。

## 落地順序(去風險後)

### 第 0 批 — 立即出貨的 quickWins(全單檔、近零回歸、情感/正確性 ROI 最高)
1. 凌晨問候語:`copy.ts` `hour<5` 回「晚安」傷趕工承辦 → 改「夜深了,{name}」。
2. 補 `/admin/scores` 進側欄「管理」群 + ⌘K(現為黑洞)。
3. `changeExecStatus` 的 `window.confirm` → `ConfirmDialog`(會默默清掉已填完成日/逾期原因的真 bug)。
4. `ConfirmDialog` tone=danger 初始焦點落「取消」鈕(避免 Enter 直接刪)。
5. `Dialog` 加 `max-h-[85dvh]` + 內容 overflow + 窄螢幕 footer 全寬(手機叫鍵盤後確認鈕被推出畫面)。
6. 角色稱謂統一(一人三名 → 單一稱呼)。
7. 匯出按鈕加「此檔給誰用」副標(遞交版 vs 工作底稿)。
8. 週期頁 Chip 與 Stepper 文案先對齊止血(完整 stage SoT 留地基)。

### 第 1 批 — 兩道真承重牆(SoT)+ 文案 SoT(可並行;需等價測試保護)
- `lib/nav-map.ts`:宣告式路由地圖,Sidebar/⌘K/各頁麵包屑全衍生。**先與現況並存比對(測試 assert 等價)再刪舊碼**。
- `lib/stage.ts`:整合 7 態 × 4 步為一份;Stepper/Chip/服務卡/nextAction 全派生。**7 狀態×3 角色快照測試**。
- `copy.ts` 擴為文案 SoT:角色稱謂/階段名/狀態動詞/錯誤訊息/術語表(純資料層、零 UI 回歸)。

### 第 2 批 — 最大直覺破口:checklist 救出隱形死路
- 把 `checklistFilled/Total/SubmittedAt/OpenComments` 納入 `deriveCycleFacts` 與 `nextActionForRole`;機關未送=「填報檢核表(X/Y)」、委員=「逐題審閱(N 待補)」、中心=「退回重填或推進」。改動集中 `process-guide.ts`,風險可控。
- `nextActionForRole` 補滿 7 狀態×3 角色,不留純被動死句(沒事做也要說「在等誰/等什麼」)。

### 第 3 批 — 焦點與狀態顯性化(中風險,配 UAT 變更說明)
- 週期頁 ModuleTile 依階段對非當期模組降權(muted+「X 階段後開放」,**不隱藏**避免「功能不見了」客訴)。
- 矯正 PENDING 給「開始填報」主鈕;退回/繳交鎖定改**事前 inline 預告後果**。

### 第 4 批 — 行動/無障礙基線(部分可獨立先做)
- `@media (pointer:coarse)` 讓 Button/IconButton/Chip 命中區 ≥44px(純 CSS、全站受益、政府無障礙剛需,**可獨立於元件重構先做**)。
- Tabs roving tabindex + aria;手機 TopStrip 返回鈕;`prefers-reduced-motion`。
- 之後再補 axe-core/Playwright viewport 回歸 CI。

### 延後(非地基,依證據再評)
role-view 骨架分流 · ds-lint 強制 · 一卡一彩底 · surface 階梯 · 週期持久次級導航。

## 改造風險與防護(PM 提示)
- nav-map/stage 是 10 家醫院每天看的東西 → **先並存比對 + 快照測試,確認等價才切換,絕不大爆炸**。
- 已在 UAT 數週,肌肉記憶已建 → 結構性改動配變更說明;降權用 muted 不隱藏。
- 解序列耦合:quickWins 與 copy SoT 並行先出;role-view 移出關鍵路徑;a11y 觸控基線可獨立先做。
